# MRF Monitor setup

The MRF Monitor currently runs without a remote database or API. Records are stored in this browser's local storage so the interface and workflow remain available while the replacement Google Sheet and Drive locations are being prepared.

## Notes

- The frontend limits uploads to 5 MB.
- Clearing browser storage removes the local MRF records.
- A future backend can replace the local storage module after the new Sheet and Drive locations are supplied.
